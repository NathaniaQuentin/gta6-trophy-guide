An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 — official names, descriptions and grades, a roadmap to the platinum, missable flags, and a cited guide for every trophy. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Or serve the guide itself with `node serve.ts` and open http://localhost:8080 — it works with the network off.
